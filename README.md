<img width="49%" src="https://res.cloudinary.com/ditl4wkej/image/upload/waqtak/manager-01-dashboard.png" alt="Waqtak manager dashboard"/>
<img width="49%" src="https://res.cloudinary.com/ditl4wkej/image/upload/waqtak/employee-01-home.png" alt="Waqtak employee screen"/>

<br/><br/>

**One system for PlayStation lounges, PC gaming and internet cafés** — an Arabic-first alternative to PanCafe that keeps working when the internet doesn't.

</div>

<table>
<tr><td width="50%" valign="top">

**⚡ What it does**

- 🖥️ &nbsp;**Device control** — lock / unlock PCs and consoles, auto time metering
- 🧾 &nbsp;**Point of sale** — a separate running bill per device
- 🔄 &nbsp;**Shifts** — handover with exact cash reconciliation
- 📦 &nbsp;**Inventory by recipe** — sell a sandwich, deduct its ingredients
- 🎟️ &nbsp;**Memberships & offers** — recurring plans, promo pricing
- 📶 &nbsp;**Wi-Fi vouchers** — generate and sell hotspot cards from the POS

</td><td width="50%" valign="top">

**🧠 The hard parts**

- 🔌 &nbsp;**Offline-first** — runs **5 days** with no connection, then reconciles
- 🌍 &nbsp;Owner watches **every branch remotely**, from any device
- 🖨️ &nbsp;Arabic on thermal printers → [`receipt-image-printer`](https://github.com/ashrafeldawody/receipt-image-printer)
- 📡 &nbsp;Hotspot voucher sales → [`mikrotik-voucher-manager`](https://github.com/ashrafeldawody/mikrotik-voucher-manager)
- 💡 &nbsp;Cutting power to a console → [`sonoff-switch-sdk`](https://github.com/ashrafeldawody/sonoff-switch-sdk)
- 🎮 &nbsp;PlayStation tooling → [`PSX-Inject`](https://github.com/ashrafeldawody/PSX-Inject)

</td></tr>
</table>
