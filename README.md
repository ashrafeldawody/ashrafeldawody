## Waqtak

<a href="https://waqtak.app"><img src="https://res.cloudinary.com/ditl4wkej/image/upload/waqtak/manager-01-dashboard.png" width="100%" alt="Waqtak manager dashboard"/></a>

One offline-first system for gaming and internet cafés, Arabic-first, built to keep working when the internet doesn't.

- Electron desktop app, React Native mobile app, and a PC client agent that locks and controls customer machines
- Device control and time metering for consoles and PCs, with power cut through smart switches
- Point of sale with a running bill per device, shift handover with cash reconciliation, inventory by recipe
- MikroTik integration to generate and sell WiFi hotspot vouchers from the POS
- Payroll, memberships, financial analytics, and automated backups
- Runs for days with no connection, then reconciles. Owners watch every branch remotely

Several of the repos below started as a piece of Waqtak.
