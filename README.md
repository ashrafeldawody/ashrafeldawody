<br/>

> **One system for PlayStation lounges, PC gaming and internet cafés** — an affordable Arabic-first alternative to PanCafe that keeps working when the internet doesn't.

<table>
<tr><td width="50%" valign="top">

**What it does**

- 🖥️ &nbsp;**Device control** — lock / unlock PCs and consoles, automatic time metering
- 🧾 &nbsp;**Point of sale** — a separate running bill per device
- 🔄 &nbsp;**Shifts** — handover with exact cash reconciliation
- 📦 &nbsp;**Inventory with recipes** — sell a sandwich, deduct its ingredients
- 🎟️ &nbsp;**Memberships & offers** — recurring plans and promo pricing
- 📶 &nbsp;**Wi-Fi vouchers** — generate and sell hotspot cards from the same POS

</td><td width="50%" valign="top">

**The hard parts**

- 🔌 &nbsp;**Offline-first** — runs up to **5 days** with no connection, then reconciles
- 🌍 &nbsp;Owner watches **every branch remotely**, from any device
- 🖨️ &nbsp;Arabic on thermal printers → [`receipt-image-printer`](https://github.com/ashrafeldawody/receipt-image-printer)
- 📡 &nbsp;Hotspot voucher sales → [`mikrotik-voucher-manager`](https://github.com/ashrafeldawody/mikrotik-voucher-manager)
- 💡 &nbsp;Cutting power to a console → [`sonoff-switch-sdk`](https://github.com/ashrafeldawody/sonoff-switch-sdk)
- 🎮 &nbsp;PlayStation tooling → [`PSX-Inject`](https://github.com/ashrafeldawody/PSX-Inject)

</td></tr>
</table>

### 🎮 &nbsp;[PSX-Inject](https://github.com/ashrafeldawody/PSX-Inject)
`C#` &nbsp;`.NET 10` &nbsp;`WPF`

Windows proxy + download helper for **PS4 / PS5**. Routes PSN traffic through your PC, caches `.pkg` files, auto-discovers every part of a game with sizes, and exports clean links you can paste into IDM. Self-contained single-file build.
