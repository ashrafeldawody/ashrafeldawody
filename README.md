## Selected code

[**mikrotik-voucher-manager**](https://github.com/ashrafeldawody/mikrotik-voucher-manager) — one TypeScript client for both MikroTik Hotspot and User Manager voucher flows, instead of two incompatible ones.

[**receipt-image-printer**](https://github.com/ashrafeldawody/receipt-image-printer) — renders receipts as images so thermal printers can print any language. Arabic, Chinese, Turkish. No codepages.

[**sonoff-switch-sdk**](https://github.com/ashrafeldawody/sonoff-switch-sdk) — drives Sonoff smart switches from JavaScript. The layer that cuts power to a console when the time runs out.

[**PSX-Inject**](https://github.com/ashrafeldawody/PSX-Inject) — PS4/PS5 download helper for Windows. Routes PSN traffic through your PC, caches `.pkg` files, finds every part of a game and exports clean links. C#, WPF.

[**online-exam-system**](https://github.com/ashrafeldawody/online-exam-system) — an online examination platform in pure PHP.

[**GYM-APP**](https://github.com/ashrafeldawody/GYM-APP) — role-based gym management across cities and branches. Laravel.

The first three came out of building Waqtak. [The rest](https://github.com/ashrafeldawody?tab=repositories).
